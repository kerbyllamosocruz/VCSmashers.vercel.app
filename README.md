# 🏸 Badminton Court Reservation System

A **badminton court reservation system** that allows players to schedule games, manage bookings, and make secure payments online.  
Designed to simplify court management, it provides an intuitive interface for users to **reserve courts**, **track availability**, and **complete transactions with ease**.

---

## 📋 Features

- 🗓️ **Court Scheduling** – Reserve badminton courts with date and time selection.  
- 👥 **User Management** – Players can register, log in, and view their reservations.  
- 💳 **Online Payments** – Integrated with **PayMongo** for secure payment processing.  
- 📅 **Availability Tracking** – Prevents double booking and shows real-time slot updates.  
- ⚙️ **Admin Dashboard** – Manage courts, bookings, and payment status efficiently.  
- ✉️ **Booking Confirmation** – Automated notifications for reservations and payments.

---




## 🛠️ Tech Stack

- **Frontend:** HTML, CSS (Tailwind), JavaScript  
- **Backend:** PHP (procedural or with lightweight structure)  
- **Database:** MySQL  
- **Payments:** PayMongo API
